## الخطوة 2 — السوبر أدمن ينشئ الحسابات

بعد إرسال الملف، هذه الخطوات التي يُنفَّذ كل منها للموظف الواحد:

### إنشاء حساب جديد

1. افتح `https://app.elkheima.com/login` بحساب `super_admin`.
2. اذهب إلى **Admin → Super Admin Control Center → Users**.
3. اضغط **Create New Account**.
4. اختر سجل HR المرتبط بالموظف (الاسم يظهر تلقائيًا من قائمة HR).
5. راجع البريد والدور واللغة ← اضغط **Create Account Securely**.
6. أدخل كلمة مرور السوبر أدمن + كود TOTP + السبب (مثال: `إنشاء حساب REL-15 UAT`).
7. **انسخ البيانات التي تظهر مرة واحدة فقط:**
   - كلمة المرور المؤقتة ← أرسلها للموظف بشكل آمن
   - رمز التسجيل (enrollment token) ← فقط لـ `accountant` و`super_admin` و`owner`
8. أغلق النافذة ← البيانات لن تظهر مجدداً.

### إنشاء أول `timeshare_admin`

نفس الخطوات أعلاه مع اختيار دور `timeshare_admin`.
يستطيع `timeshare_admin` بعدها إنشاء `timeshare_agent` بنفس الطريقة من قائمة HR.

## مشاكل شائعة وحلولها

| المشكلة | الحل |
|---|---|
| الشاشة فارغة / أصفار | الجلسة انتهت ← أعد الدخول. المحاسب: تأكد إتمام إعداد 2FA |
| "403 Forbidden" على إجراء | الصلاحية غير موجودة ← أبلغ السوبر أدمن |
| كود TOTP مرفوض | تأكد أن وقت الهاتف تلقائي (Settings → Auto time) |
| المعاملة لا تظهر بعد الإرسال | انتظر دقيقة وأعد التحميل. إذا استمر: أبلغ المشرف |
| نسيت كلمة المرور | `/forgot-password` ← سيُرسل رابط للبريد |
| ضاع جهاز TOTP | استخدم كود استرداد. إذا نفدت الأكواد: اتصل بالسوبر أدمن لـ Force 2FA Reset |
| ظهرت شاشة اختيار فرع | أوقف التجربة وأبلغ السوبر أدمن فوراً |
