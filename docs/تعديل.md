### 1.4 تفاصيل إنجازات 2026-07-26

#### PMS accrual journal (commit `e83020c`)
الدورة المحاسبية الصحيحة للغرف:
- `checkin_booking` → يسجّل `Dr.1150 / Cr.4100` (اعتراف بالإيراد عند الدخول، accrual basis)
- `checkout_booking` → يسجّل `Dr.1100|1110|1120 / Cr.1150` (تسوية الذمة حسب payment_method)
- متوافق مع Opera/Mews/Cloudbeds — الإيراد يُعرَف عند الدخول لا عند الخروج
- `strict=False` في checkin عشان check-in ميتوقفش لو حسابات ناقصة

#### Dining cross-outlet revenue (commit `e83020c`)
- `DiningOrderItem.outlet_id` — عمود جديد NULLable (FK → dining_outlets، SET NULL)
- `_build_outlet_revenue_splits` — يجمع subtotal per-outlet من أصناف الطلب
- `_post_folio_revenue_splits` — قيود Dr.1150/Cr.outlet.revenue_account per-outlet
- `_settle_room_tender` + `_settle_direct_tender` — محدّثان لـ outlet_splits
- Migration `43493c94dc2c` — مطبّق فعلاً على DB
- 3 tests جديدة: single-outlet، cross-outlet (2 قيود)، NULL fallback

#### Cashier improvements (commit `50b2fee`)
**CashControlPanel:**
- `direction` select (increase/decrease) — إجباري لـ `correction`، validation قبل PIN
- الـ ledger يعرض `direction` badge (📈/📉) + `destination` للـ `safe_drop`
- ألوان مميّزة: أخضر=cash_in/increase، أحمر=cash_out/decrease/safe_drop

**ShiftDashboardView:**
- `ShiftReport` interface — 8 حقول جديدة: `total_room`, `refunds_total/count`, `expected_cash`, `delta_vs_previous`, `cash_movements_effect/warning`
- X-Report صف ثانٍ: الكاش المتوقع + محمّل على غرف + مرتجعات + مقارنة بالوردية السابقة
- WS auto-refresh: `shift_sale` → `refreshReport()` فقط (بدون إعادة تحميل الطلبات)، `shift_closed` → `refreshAll()`
- مؤشر 🟢/🟡 في الهيدر
- `refreshReport()` منفصل عن `refreshAll()` — زر التحديث يعمل الاتنين

**ShiftPanel:**
- 3 URLs hardcoded → `ENDPOINTS.finance.shiftsCurrent/shiftHandoverNote/shiftsOpen/shiftClose`

**i18n:** 11 مفتاح جديد (direction, directionHint, expectedCash, totalRoom, refunds, deltaVsPrevious, cashMovementsEffect)

#### SuperAdmin (commit `a79681a`)
- `ENDPOINTS.core.auditLogs` جديد في endpoints.ts
