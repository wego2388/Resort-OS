# دليل التوثيق الحالي — El Kheima Resort OS

**آخر تحديث:** 2026-07-31 بعد نشر إصلاح تبديل منافذ الـPOS
**قائد التنفيذ والمراجع النهائي:** Codex، بتكليف Mohamed

هذا الملف هو بوابة التوثيق الوحيدة. أي وكيل أو مطور يبدأ من هنا بعد
`AGENTS.md` و`CLAUDE.md`.

## ترتيب القراءة الإلزامي

1. `AGENTS.md` — قواعد المستودع والسلامة.
2. `CLAUDE.md` — الدستور الهندسي الثابت.
3. `wagdy.md` — قرارات Mohamed والأولوية البشرية الحالية.
4. `PROJECT_STATUS.md` — سجل الحقيقة التقنية المؤرخة.
5. `docs/audits/EL_KHEIMA_FINAL_EXECUTION_PLAN_AR.md` — الخطة الحية والبوابات.
6. `docs/agent-workflow/EL_KHEIMA_EXECUTION_BOARD.md` — المهمة الحالية فقط.
7. أحدث handoff مشار إليه في لوحة التنفيذ.

## القرارات الناسخة الحالية

- الخيمة لها فرع تشغيلي واحد فقط حاليًا.
- لا يوجد Branch Switcher ظاهر؛ عزل الفرع يظل fail-closed داخليًا.
- Codex يقود التنفيذ والمراجعة النهائية.
- الإنتاج domain-based: `elkheima.com` و`www.elkheima.com` للموقع،
  و`app.elkheima.com` للموظفين، على VPS `191.218.161.133`.
- Resort release الفعال `a3e8abb` وMarketing release الفعال `16f8f2c`؛
  أي نشر لاحق يحتاج backup وrollback وhealth evidence جديدًا.
- البيانات synthetic المعتمدة للعرض موجودة عبر importer محكوم وموسومة؛
  لا تُعامل كـmaster data حقيقية ولا تُنشأ بيانات demo عشوائية خارج مساره.
- Chatbot فعال ومتحقق حيًا؛ تعديل provider أو facts يحتاج governance review.
- DNS cutover مكتمل، ونقطة التراجع Hostinger snapshot `167902017`.
- دليل تدريب الموظفين العربي هو المرجع التشغيلي المعتمد قبل UAT؛ دليل
  السوبر أدمن مرجع أمني مكمل وليس مادة لكل الموظفين.

## ترتيب تحديث الحالة

عند تغير قرار أو حالة Gate:

1. تحديث `wagdy.md` أولًا.
2. تحديث `PROJECT_STATUS.md` بالأدلة.
3. تحديث الخطة إذا تغير Gate أو شرط قبول.
4. تحديث لوحة التنفيذ بالمهمة الجارية فقط.
5. إنشاء handoff عند إغلاق حزمة أو تغيير إنتاج.
6. نقل أي موجز superseded إلى `docs/archive/` بدل ترك أوامر متعارضة.

لا تنسخ checkpoint كاملًا بين عدة ملفات. استخدم الروابط، واكتب في كل ملف
المعلومة التي تخص دوره فقط.

`docs/archive/2026-07-execution/`. وجودها لأغراض التدقيق فقط ولا يمنح إذنًا
بتنفيذ أي خطوة منها.
